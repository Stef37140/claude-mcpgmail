# Regles de confidentialite - Claude MCP Gmail

Cette application est un outil personnel. Elle n'est utilisee que par son proprietaire, pour ses propres comptes Gmail et ceux de sa famille, avec leur accord.

Donnees consultees : les messages, libelles et parametres Gmail des comptes autorises, uniquement lorsque le proprietaire en fait la demande via Claude Desktop.

Stockage : les jetons OAuth sont stockes localement sur l'ordinateur du proprietaire. Aucune donnee n'est stockee sur un serveur tiers par cette application, ni vendue, ni partagee, ni utilisee a des fins publicitaires.

Revocation : chaque titulaire de compte peut retirer l'acces a tout moment depuis https://myaccount.google.com/permissions

L'utilisation des donnees recues des API Google respecte la Google API Services User Data Policy, y compris les exigences d'utilisation limitee (Limited Use).

Contact : via l'adresse e-mail d'assistance indiquee sur l'ecran de consentement Google.
